PROMPT 01 · พรอมต์หลักสร้างเกมขับรถ 3 เลนด้วย Three.js ทั้งเกม

คุณเป็นนักพัฒนาเกมเว็บ ช่วยสร้างเกมขับรถหลบสิ่งกีดขวางแบบ 3 เลน ด้วย Three.js เป็นไฟล์ HTML ไฟล์เดียว มีแอนิเมชัน เล่นได้ทั้งคอมพิวเตอร์และมือถือ

# ข้อมูลเกม
- ชื่อเกม: [ชื่อเกม]
- สีรถผู้เล่น: [สีรถผู้เล่น]
- ธีมฉาก: [ธีมฉาก เช่น กลางวัน / พระอาทิตย์ตก / กลางคืน]

# แนวคิดเกม
- เป็นเกมเลื่อนฉากด้านข้าง ถนนวางแนวนอนบนหน้าจอ มี 3 เลน คือเลนบน เลนกลาง เลนล่าง
- รถผู้เล่นอยู่ด้านซ้ายของจอ เคลื่อนที่ได้เฉพาะขึ้นและลงระหว่างเลนเท่านั้น (ไม่ขยับซ้ายขวา) ผู้เล่นเลือกได้ว่าจะไปเลนบน กลาง หรือล่าง
- สิ่งกีดขวางเคลื่อนที่จากขวาไปซ้าย ชนแล้วเกมจบทันที
- สิ่งกีดขวางมี 3 แบบ
  1) รถยนต์คันเล็กที่ขับช้า (แบบแฮทช์แบ็กและกระบะ หลายสี) เคลื่อนที่ช้ากว่าฉากเล็กน้อย
  2) ต้นไม้ที่ตั้งอยู่บนถนน (สนและต้นกลม)
  3) แกะที่ยืนรออยู่ริมถนน แล้วเดินข้ามถนนตอนผู้เล่นเข้าใกล้ มีแอนิเมชันขาเดิน
- ความเร็วเริ่มต้นพอเหมาะ แล้วเพิ่มขึ้นเรื่อยๆ ตามเวลาจนถึงเพดานที่ยังเล่นได้ (ประมาณ 2 เท่าของความเร็วเริ่มต้น) ช่วงแรกยังไม่ให้มีแกะ
- ระบบสร้างสิ่งกีดขวางต้องยุติธรรม: ห้ามปิดครบทั้ง 3 เลนพร้อมกัน ต้องมีเลนว่างที่เปลี่ยนไปถึงได้เสมอ และสิ่งกีดขวางในเลนเดียวกันต้องไม่ทะลุกัน
- คะแนนคือระยะทางที่วิ่งได้ (เมตร) เก็บสถิติสูงสุดไว้ใน localStorage (ครอบด้วย try/catch)

# การควบคุม
- คอมพิวเตอร์: ลูกศรขึ้น/ลง หรือ W/S เพื่อเปลี่ยนทีละเลน และกด 1 2 3 เพื่อไปเลนนั้นโดยตรง
- มือถือ: ปัดนิ้วขึ้น/ลง เปลี่ยนทีละเลน และแตะที่เลนบนจอเพื่อไปเลนนั้นโดยตรง
- Space หรือ Enter เพื่อเริ่มและเริ่มใหม่

# หน้าจอและสถานะเกม
- หน้าเริ่มเกม: แสดงชื่อเกม วิธีเล่นทั้งคอมและมือถือ และปุ่ม "เริ่มเล่น"
- ระหว่างเล่น: HUD แสดงระยะทางและสถิติสูงสุด
- เมื่อชน: แสดง Game Over พร้อมเอฟเฟกต์ชน (เศษชิ้นส่วนกระเด็น กล้องสั่น รถหมุนและกระเด้ง ควันขึ้น) แล้วขึ้นการ์ดสรุประยะทาง สถิติสูงสุด ป้าย "สถิติใหม่" และปุ่ม "เล่นใหม่ (Restart)" ที่กดแล้วเริ่มเกมใหม่ได้ทันที

# ภาพและแอนิเมชัน (Three.js)
- โหลด Three.js r128 จาก https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js ด้วยแท็ก script เดียว (ไม่ใช้ module หรือ import map)
- สร้างโมเดลทั้งหมดจากทรงเรขาคณิตง่ายๆ แบบ low-poly ไม่ใช้ไฟล์ภายนอก: รถ (ตัวถัง ห้องโดยสาร ไฟหน้า-หลัง ล้อที่หมุนได้), ต้นไม้, พุ่มไม้, ก้อนหิน, แกะ (ขนฟู หัว ขา 4 ขา)
- กล้อง perspective มองเฉียงลงมาจากด้านบน (ประมาณ 58 องศา) เห็นถนน 3 เลนชัดเจน ฝั่งขวาคือทิศที่สิ่งกีดขวางเข้ามา
- ถนน เส้นแบ่งเลนประ ขอบถนน หญ้า และต้นไม้ข้างทางเลื่อนไปทางซ้ายตามความเร็วเกมอย่างต่อเนื่อง
- รถผู้เล่นเลื่อนเปลี่ยนเลนอย่างนุ่มนวล เอียงตัวรถเล็กน้อยตอนเลี้ยว มีฝุ่นด้านหลัง และไฮไลต์เลนที่กำลังไป
- เงาแบบ real-time (directional light) พร้อม hemisphere light และ fog สีเดียวกับท้องฟ้า โทนสีและแสงเปลี่ยนตามธีมฉากที่ระบุ

# ข้อกำหนดทางเทคนิค
- รองรับทั้ง Desktop และ Mobile: ปรับขนาดตามหน้าจอ (resize และ orientation) รองรับแนวตั้งโดยให้กล้องถอยออกมาเห็นถนนได้พอดี จำกัด pixel ratio ไม่เกิน 2
- ใช้ requestAnimationFrame และ delta time (จำกัดไม่เกิน 0.05 วินาที) เพื่อให้เกมเร็วเท่ากันทุกเครื่อง
- ใช้ Pointer Events สำหรับการปัดและแตะ ตั้ง touch-action: none ที่ canvas และกันหน้าเว็บเลื่อน/ซูมบนมือถือ
- แยกส่วนในโค้ดให้อ่านง่าย: ค่าคงที่ของเกม สร้างโมเดล ระบบ spawn สิ่งกีดขวาง ตรวจการชนด้วยกล่อง AABB อัปเดตเกม รับอินพุต
- UI ทั้งหมดเป็นภาษาไทย ใช้ฟอนต์ Kanit หรือ Noto Sans Thai จาก Google Fonts

ส่งกลับมาเป็นโค้ด HTML ฉบับสมบูรณ์ในบล็อกเดียว ไม่ต้องอธิบายเพิ่ม
💡 วางพรอมต์นี้ในแชตใหม่ของ Claude ต้องต่ออินเทอร์เน็ตตอนเล่น เพราะเกมโหลด Three.js จาก CDN

PROMPT 02 · พรอมต์เสริมปรับความยาก และเพิ่มสิ่งกีดขวางใหม่

ช่วยปรับเกมข้างบนต่อ โดยคงโครงสร้างโค้ดและการควบคุมเดิมไว้ แล้วส่งกลับมาเป็นโค้ด HTML ฉบับสมบูรณ์

- ระดับความยาก: [ง่าย / ปานกลาง / ยาก] (ปรับความเร็วเริ่มต้น ความเร็วสูงสุด และระยะห่างระหว่างสิ่งกีดขวาง)
- เพิ่มสิ่งกีดขวางชนิดใหม่ 1 อย่าง: [เช่น กรวยจราจร / ไก่ข้ามถนน / จักรยาน / ก้อนหินกลิ้ง] พร้อมโมเดล low-poly และพฤติกรรมของมันเอง
- เพิ่มไอเทมเก็บระหว่างทาง: [เช่น เหรียญ / โล่กันชน 1 ครั้ง] พร้อมแสดงจำนวนที่เก็บได้ใน HUD

ข้อกำหนดเพิ่มเติม
- ห้ามทำให้ปิดครบ 3 เลนพร้อมกัน ต้องมีทางรอดเสมอ
- ยังรองรับมือถือและคอมพิวเตอร์เหมือนเดิม
💡 ใช้ต่อในแชตเดิมหลังได้เกมจากพรอมต์หลักแล้ว
สิ่งที่คุณจะได้รับ

เกมที่ Claude สร้างให้มีอะไรบ้าง

  • ✓ฉาก 3D แบบ low-polyถนน 3 เลน ต้นไม้ข้างทาง เงา และหมอก สร้างจากทรงเรขาคณิตล้วน
  • ✓สิ่งกีดขวาง 3 แบบรถเล็กขับช้า ต้นไม้ และแกะที่เดินข้ามถนน แต่ละอย่างมีพฤติกรรมต่างกัน
  • ✓ความยากที่ค่อยๆ เพิ่มความเร็วขึ้นตามเวลา และระบบสุ่มที่ไม่ปิดทางรอดทั้ง 3 เลน
  • ✓Game Over และ Restartมีเอฟเฟกต์ชน สรุปคะแนน สถิติสูงสุด และเริ่มใหม่ได้ทันที
  • ✓คอมและมือถือใช้คีย์บอร์ดหรือปัดและแตะ ปรับกล้องตามจอแนวตั้งและแนวนอน
  • ✓HTML ไฟล์เดียวไม่ต้องติดตั้งอะไร ต่ออินเทอร์เน็ตเพื่อโหลด Three.js แล้วเปิดเล่นได้เลย
คำถามที่พบบ่อย

ก่อนเริ่มใช้

ต้องเสียเงินหรือสมัครสมาชิกไหม?

คัดลอกพรอมต์ไปใช้ได้ฟรี ส่วน Claude ใช้แพ็กเกจฟรีได้ แต่โควตาการใช้งานขึ้นอยู่กับแพ็กเกจของคุณ

ต้องเขียนโค้ดเป็นไหม?

ไม่ต้อง บันทึกโค้ดที่ได้เป็นไฟล์ .html แล้วเปิดด้วยเบราว์เซอร์ได้เลย ถ้าอยากแก้ต่อ ก็พิมพ์บอก Claude ในแชตเดิม

เกมที่ได้จะเหมือนเกมตัวอย่างเป๊ะไหม?

ไม่เหมือนเป๊ะ Claude อาจออกแบบรถ ฉาก และตัวเลขต่างจากตัวอย่างเล็กน้อย แต่กติกา การควบคุม และสิ่งกีดขวางจะเป็นไปตามพรอมต์

เกมไม่ทำงานหรือจอขาว ทำอย่างไร?

เช็กว่าต่ออินเทอร์เน็ตอยู่ เพราะเกมโหลด Three.js จาก CDN ถ้ายังไม่ได้ ให้ก๊อปข้อความผิดพลาดจากคอนโซลของเบราว์เซอร์ไปบอก Claude ในแชตเดิม แล้วขอให้แก้

อยากปรับเกมต่อ ทำอย่างไร?

พิมพ์บอก Claude ในแชตเดิมได้เลย เช่น "ให้ถนนมี 4 เลน" หรือ "เพิ่มเสียงตอนชน" หรือใช้พรอมต์เสริมด้านบน

พร้อมสร้างเกมของคุณแล้วหรือยัง?

คัดลอกพรอมต์หลัก ตั้งชื่อเกมของคุณ แล้วให้ Claude สร้างเกมให้ในครั้งเดียว
