Prompt 01 · พรอมต์หลักสร้าง Landing Page ขายสินค้าดิจิทัลทั้งหน้า

คุณเป็น Web Designer และ Copywriter มืออาชีพ ช่วยสร้าง Landing Page สำหรับขายสินค้าดิจิทัลเป็นไฟล์ HTML ไฟล์เดียว (CSS อยู่ใน <style> ไม่ใช้ framework) เปิดในเบราว์เซอร์ได้ทันที

# ข้อมูลสินค้า
- ชื่อสินค้า: [ชื่อสินค้า]
- กลุ่มเป้าหมาย: [กลุ่มเป้าหมาย]
- ปัญหาหลักที่แก้: [ปัญหาหลัก]
- ผู้ขาย: [ชื่อผู้ขาย]
- แพ็กเกจ: [ชื่อแพ็กเกจ 1] [ราคา] / [ชื่อแพ็กเกจ 2] [ราคา] / [ชื่อแพ็กเกจ 3] [ราคา]
- ลิงก์ชำระเงิน: [ลิงก์ชำระเงินของแต่ละแพ็กเกจ]

# โครงหน้า (เรียงตามนี้)
1. Hero: kicker เล็กๆ, พาดหัวใหญ่ที่เน้นคำสำคัญด้วยสีหลัก, คำโปรย 2-3 บรรทัด, ปุ่มหลัก (เลื่อนไป #pricing) + ปุ่ม ghost (เลื่อนไป #problem), ข้อความโน้ตเล็กใต้ปุ่ม และภาพจำลองสินค้า (เช่นปกหนังสือ) ทางขวาที่เอียงเล็กน้อย
2. Problem: การ์ด 3 ใบ "เคยเป็นแบบนี้ไหม?" ใบละ 1 emoji, หัวข้อ, คำอธิบายสั้น
3. Solution: พื้นหลังสีเข้ม การ์ด 3 ขั้นตอนที่มีเลขลำดับ 01 02 03 (ใช้ CSS counter)
4. Reviews: รีวิว 3 รายการ มีดาว, ข้อความ, avatar อักษรตัวแรก, ชื่อ-อาชีพ-อายุ และหมายเหตุตัวเล็กว่า "รีวิวเป็นตัวอย่างประกอบหน้าเว็บ ผลลัพธ์ขึ้นอยู่กับแต่ละบุคคล"
5. What you get: รายการสิ่งที่ได้รับ 5-6 ข้อ แบบ 2 คอลัมน์ มีเครื่องหมาย ✓ พื้นหลังสีพีช
6. Pricing id="pricing": แพ็กเกจ 3 ระดับ ใบกลางเป็น featured ขอบสีหลัก ยกสูงขึ้นเล็กน้อย มีป้าย "คุ้มที่สุด" ปุ่มซื้อของแต่ละใบลิงก์ไปยังลิงก์ชำระเงินของแพ็กเกจนั้น ใส่ HTML comment TODO ไว้เหนือปุ่มให้เปลี่ยนลิงก์
7. Guarantee: กล่องรับประกันความพอใจ 14 วัน
8. Footer: ลิขสิทธิ์ปี 2026 และชื่อผู้ขาย

# สไตล์
- ภาษาไทย ใช้ฟอนต์ Noto Sans Thai จาก Google Fonts (น้ำหนัก 300-800), line-height 1.75
- โทนอบอุ่นสะอาดตา: พื้นหลังครีม #fdfaf5, ตัวอักษร #2b2620, สีหลักเขียว #2e7d5b (เข้ม #1f5c42, อ่อน #e6f2ec), สีเน้นส้ม #e8842c, พีช #ffede0
- กำหนดสีทั้งหมดเป็น CSS variables ใน :root
- มุมโค้ง 16-20px เงานุ่ม ปุ่มทรงแคปซูล มี hover แบบยกขึ้นเล็กน้อย
- กว้างสุด 1040px, scroll-behavior: smooth
- Responsive: ที่ความกว้าง ≤ 820px ทุก grid เป็นคอลัมน์เดียว ซ่อนภาพจำลองสินค้า

# ข้อกำหนดเนื้อหา
- เขียนข้อความขายเป็นภาษาไทยที่เป็นธรรมชาติ ไม่โอเวอร์ ไม่สัญญาผลลัพธ์เกินจริง ไม่อ้างตัวเลขหรือรีวิวว่าเป็นของจริง
- ปรับเนื้อหาทุกส่วนให้ตรงกับสินค้าและกลุ่มเป้าหมายที่ให้ไว้ข้างต้น

ส่งกลับมาเป็นโค้ด HTML ฉบับสมบูรณ์ในบล็อกเดียว ไม่ต้องอธิบายเพิ่ม
💡 วางพรอมต์นี้ในแชตใหม่ของ Claude แล้วคัดลอกโค้ดที่ได้ไปบันทึกเป็นไฟล์ landing.html

Prompt 02 · พรอมต์เสริมปรับโทนสี ฟอนต์ และบุคลิกแบรนด์

ช่วยปรับดีไซน์ของ Landing Page ข้างบนให้เข้ากับแบรนด์ของฉัน โดยไม่เปลี่ยนโครงหน้าและเนื้อหา

- บุคลิกแบรนด์: [เช่น มินิมอล / สนุกสดใส / หรูหรา / จริงจังน่าเชื่อถือ]
- สีหลักของแบรนด์: [รหัสสี เช่น #3b5bdb]
- ฟอนต์หัวข้อที่ชอบ: [ชื่อฟอนต์จาก Google Fonts ที่รองรับภาษาไทย]

ให้แก้เฉพาะ CSS variables ใน :root, ฟอนต์ และรายละเอียดตกแต่ง (มุมโค้ง เงา พื้นหลัง hero) ให้เข้ากับบุคลิกที่ระบุ และตรวจว่าตัวอักษรบนพื้นหลังทุกส่วนยังอ่านง่าย (contrast พอ) ส่งกลับเป็น HTML ฉบับสมบูรณ์
💡 ใช้ต่อในแชตเดิมหลังได้ผลลัพธ์จากพรอมต์หลักแล้ว

Prompt 03 · พรอมต์เสริมตรวจและเกลาข้อความขายให้โน้มน้าวขึ้น

ช่วยรีวิวข้อความขายใน Landing Page ข้างบนในฐานะ Copywriter สาย conversion

1. ชี้จุดที่ข้อความคลุมเครือ ยาวเกินไป หรือฟังดูเกินจริง
2. เสนอพาดหัว Hero ใหม่ 3 แบบ (เน้นผลลัพธ์ / เน้นปัญหา / เน้นความง่าย) ให้ฉันเลือก
3. ตรวจว่าส่วนรีวิว ตัวเลข และรับประกัน ไม่อ้างสิ่งที่เป็นไปไม่ได้หรือแสดงว่าเป็นข้อมูลจริง ถ้าเป็นตัวอย่างต้องมีหมายเหตุกำกับ

หลังจากฉันเลือกพาดหัว ให้ส่ง HTML ฉบับแก้ไขสมบูรณ์กลับมา
💡 ช่วยให้ข้อความขายน่าเชื่อถือขึ้นก่อนเปิดขายจริง
คำถามที่พบบ่อย

ก่อนเริ่มใช้งาน

ต้องเสียเงินหรือสมัครสมาชิกไหม?

ไม่ต้อง คัดลอกพรอมต์ไปใช้ได้เลย ส่วนตัว Claude สามารถใช้แพ็กเกจฟรีได้ แต่โควต้าการใช้งานขึ้นอยู่กับผู้ให้บริการ

ต้องเขียนโค้ดเป็นไหม?

ไม่ต้อง แค่บันทึกโค้ดที่ได้เป็นไฟล์ .html แล้วเปิดด้วยเบราว์เซอร์ ถ้าอยากให้คนอื่นเข้าถึงได้ ค่อยอัปโหลดขึ้น GitHub Pages หรือ Netlify

ปุ่มชำระเงินต้องทำอย่างไร?

สร้าง Payment Link จากบริการรับชำระเงินที่คุณใช้ เช่น Stripe แล้วนำลิงก์มาใส่ในช่อง [ลิงก์ชำระเงิน] ของพรอมต์ ก่อนเปิดขายจริงควรทดสอบกดซื้อด้วยตัวเองหนึ่งครั้ง

ผลลัพธ์ไม่ตรงใจ ทำอย่างไร?

พิมพ์บอก Claude ต่อในแชตเดิมได้เลย เช่น "ทำพาดหัวให้สั้นลง" หรือใช้พรอมต์เสริม 02 และ 03 ด้านบน

พร้อมสร้างหน้าขายของคุณแล้วหรือยัง?

กลับไปคัดลอกพรอมต์หลัก แก้ข้อมูลสินค้า แล้วให้ Claude ทำส่วนที่เหลือ
